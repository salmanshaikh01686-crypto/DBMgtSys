# DBMgtSys - Database Security Management System

## About the Project

DBMgtSys is a database security management project developed to protect databases from unauthorized access and modifications.

The system focuses on managing database users and their permissions. It helps control who can access the database and what operations they are allowed to perform.

## Features

- User login and authentication
- Database access control
- User permission management
- Protection against unauthorized database access
- Management of database users
- Secure database operations
